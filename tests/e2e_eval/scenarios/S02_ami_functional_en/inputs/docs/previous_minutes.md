# Meeting Minutes — Remote control project: kick-off
**Date:** 2026-11-02  

## Summary

The project manager introduced the new remote control project: the remote has to be original, trendy and user friendly, and the design has three stages, each with individual work followed by a meeting. The team members introduced themselves and tried out the whiteboard. The project manager presented the project finance, and the team discussed first ideas about the features of the remote.

## Decisions

- The remote will sell for 25 Euro.
- The remote will be sold on an international scale.
- The production cost must not exceed 12.50 Euro.
